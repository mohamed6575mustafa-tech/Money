# مصروف البيت (Home Budget Manager)

**"خطط .. سجل .. وفر"**

تطبيق أندرويد متكامل لإدارة ميزانية ومصاريف الأسرة باللغة العربية واتجاه **RTL** الكامل، مبني باستخدام **Kotlin** و**Jetpack Compose** و**Material Design 3** مع دعم العمل دون إنترنت (Offline-First) عبر **Room** والمزامنة السحابية الفورية للأسرة عبر **Firebase Firestore**، ومساعد مالي ذكي مدعوم بـ **Firebase AI Logic (Gemini)**.

> **ملاحظة تقنية حول بيئة التطوير:** تم بناء هذا المشروع كتطبيق **Android أصيل (Native Kotlin + Jetpack Compose + Gradle)** ليتوافق مع بيئة البناء الحالية وإخراج ملف APK قياسي للأندرويد.

---

## أبرز المميزات المنفذة

- **هوية عربية RTL متكاملة**: واجهات عربية كاملة، خطوط `Cairo` و`Tajawal` مضمنة محلياً، دعم الوضع النهاري والليلي، والعملة الافتراضية الجنيه المصري (`EGP`) مع دعم (`SAR`, `AED`, `KWD`, `USD`, `EUR`).
- **شاشة تخصيص المظهر (Color Wheel حقيقي)**: عجلة ألوان تفاعلية 2D HSV (`Canvas` + سحب باللمس)، شريط إضاءة (Brightness)، معاينة مباشرة لبطاقات التطبيق قبل الحفظ، ثيمات مقترحة جاهزة، وحساب تلقائي لتباين النصوص (WCAG Contrast)، مع حفظ الإعدادات عبر **DataStore**.
- **أيقونة تطبيق 3D Adaptive Launcher Icon**: منزل عصري مع محفظة وعملات ذهبية وسهم توفير بلون أخضر زمردي وذهبي، مهيأة بجميع المقاسات (`mdpi` حتى `xxxhdpi`) وملفات Adaptive XML.
- **حساب مالي دقيق دون أخطاء عشرية**: تخزين جميع المبالغ بوحدة القروش (`Long`) وتحويل المدخلات عبر `BigDecimal` (يدعم الأرقام العربية والإنجليزية).
- **إدارة المصروفات والدخل والميزانية**:
  - 12 تصنيفاً رئيسياً + إضافة/تعديل تصنيفات مخصصة.
  - إرفاق صورة الفاتورة عبر **Android Photo Picker** بدون طلب صلاحيات تخزين واسعة.
  - ميزانية شهرية وإجمالي أو حسب التصنيف، تنبيهات 70% / 90% / 100%، خيار منع تجاوز الميزانية، ترحيل الفائض، وإغلاق الشهر مع أرشفة تاريخية.
- **مركز التخطيط الأسري**:
  - **المخصصات السنوية (Sinking Funds)**: أهداف ادخار مستقلة مع سجل إيداع/سحب لا يُحتسب كمصروف ضمن ميزانية الشهر.
  - **قائمة المشتريات الدورية**: تصنيف يومي/أسبوعي/شهري/عند الحاجة، مع تحويل آمن إلى مصروف فعلي دون تكرار.
  - **مخزون المنزل**: متابعة الكميات، تنبيهات الحد الأدنى وتواريخ الصلاحية، وإضافة سريعة لقائمة المشتريات.
  - **المراجعة الأسبوعية (15 دقيقة)**: مؤقت تنازلي حي وقائمة تحقق تفاعلية من 5 خطوات.
- **التقارير والتحليلات**: تقارير يومية/أسبوعية/شهرية/سنوية، رسوم بيانية تفاعلية (دائري Donut + أعمدة مقارنة الدخل والمصروف)، وتصدير **PDF** و**CSV/Excel** ومشاركتها عبر `FileProvider`.
- **الأسرة والمزامنة والذكاء الاصطناعي**:
  - العمل محلياً فوراً بدون حساب، أو تسجيل الدخول بحساب Google (`CredentialManager`) للمزامنة الفورية عبر Firestore ومشاركة كود دعوة الأسرة والأدوار.
  - نسخ احتياطي واستعادة بصيغة JSON عبر **Storage Access Framework (SAF)**.
  - **المستشار المالي الذكي**: محادثة فورية متصلة ببيانات الأسرة الحقيقية عبر Firebase AI Logic.

## البناء والتشغيل (Gradle)

1. بناء الحزمة التجريبية APK:
   ```bash
   gradle :app:assembleDebug
   ```
   سيتم إنتاج ملف APK في: `app/build/outputs/apk/debug/app-debug.apk`.
2. تشغيل اختبارات الوحدة وقواعد Firestore:
   ```bash
   gradle :app:testDebugUnitTest
   FIRESTORE_EMULATOR_HOST="127.0.0.1:8085" node --test firestore.test.js
   ```
3. لإصدار نسخة Production Release موقعة لمتجر Google Play، اضبط متغيرات مفتاح التوقيع (`KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_PASSWORD`) ثم نفّذ `gradle :app:bundleRelease`.
